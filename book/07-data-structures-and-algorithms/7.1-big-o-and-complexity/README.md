# 7.1 Big-O & Complexity

Before building any data structure, you need a shared language for
describing "how expensive is this operation, and how does that cost
change as the data grows?" That language is Big-O notation. Every
later chapter in this part (linked lists, stacks, queues, trees...)
leans on the vocabulary introduced here.
